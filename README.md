# swe-mm-sample-assets

PNG key frames for two sample tasks in a SWE-bench Multimodal–style dataset. The original issues only attach a
GIF or a video, which SWE-bench Multimodal tooling (e.g. SWE-agent) does not load, so the frames are hosted here as
plain images.

| Folder | Source issue | Original attachment |
|---|---|---|
| `excalidraw__excalidraw-8518/frame-1..4.png` | https://github.com/excalidraw/excalidraw/issues/8518 | animated GIF |
| `tldraw__tldraw-11112/frame-1..5.png` | https://github.com/tldraw/tldraw/issues/11112 | screen recording (MP4) |

The frames are unedited stills taken from those public attachments.
